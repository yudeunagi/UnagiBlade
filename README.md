# UnagiBlade
ゴーシュート！！

## 概要

Unity で動作する小規模な独楽（コマ）バトルシミュレーションアプリです。  
Rigidbody を持つ2つの独楽を回転させ、どちらが長く回転するかを競います。

## ゲームルール

- **回転停止** または **フィールド外への離脱** で負けとなります。
- 両方が同時に負け条件を満たした場合は引き分けです。

## 独楽の構造

各独楽は以下の3パーツで構成されます：

| パーツ | 役割 |
|--------|------|
| 上部 (Upper) | 重心上部・装飾 |
| 中間部 (Middle) | 本体 |
| 接地部 (Ground) | 地面との接触点 |

パーツは `ConfigurableJoint` で連結されており、**強い衝撃が加わるとジョイントが外れ**パーツが分離します。

## 接地形状による挙動の違い

| 形状 | 摩擦 | 回転持続 |
|------|------|---------|
| Sharp（先端が尖っている） | 少ない | 長い |
| Rounded（球面） | 中程度 | 中程度 |
| Flat（平らな円盤） | 多い | 短い |

## スクリプト一覧

| ファイル | 説明 |
|----------|------|
| `Top.cs` | 独楽全体の管理（ジョイント設定・回転監視・破壊検知） |
| `TopPart.cs` | 各パーツ（上部・中間・接地）コンポーネント |
| `GroundContactShape.cs` | 接地形状の列挙型と減衰係数ヘルパー |
| `ImpactDetector.cs` | 衝撃によるジョイント破壊トリガー |
| `Field.cs` | フィールド境界の定義とフィールド外判定 |
| `GameManager.cs` | ゲーム進行・勝敗判定 |
| `UIManager.cs` | UI 表示（カウントダウン・勝敗結果） |

## Unity シーンのセットアップ

`Assets/Scenes/BattleScene_Setup.yml` にシーンのヒエラルキー構成と  
各 GameObject のコンポーネント設定が記述されています。  
Unity エディタで新規シーンを作成し、このガイドに従って GameObjects をセットアップしてください。

## 動作環境

- Unity 2021.3 LTS 以降を推奨
- Physics エンジン: PhysX（デフォルト）
